5-Pillar Trust-Grade Architecture

PILLAR 01
Multi-Scale Dense Pyramid
Scans multi-scale pyramids from 34px to 96px across all corners using Normalized Cross-Correlation (NCC) to match the official Gemini & Imagen 3 sparkle footprint.
PILLAR 02
Sub-Pixel Quadratic Localization
Applies 2D parabolic interpolation across adjacent correlation peaks, resolving watermark coordinates with fractional sub-pixel precision to avoid edge halos.
PILLAR 03
Linear-Light Gain Sweep
Tests perceptual alpha blending in both Gamma 2.2 linear light and sRGB color space across gain sweeps (0.70 to 1.30) to verify authentic watermarks without false positives.
PILLAR 04
Fast Marching Method (Telea)
Reconstructs underlying image structures by propagating boundary pixels along image isophotes using an optimized binary min-heap priority queue.
PILLAR 05
Micro-Grain Texture Matching
Measures the surrounding background high-frequency Laplacian variance and injects matching micro-grain noise, preventing flat or blurry plastic patches.
PILLAR 06
100% Client-Side Privacy
Zero cloud servers, zero external API calls. All calculations run strictly in your browser via HTML5 Canvas and typed arrays. Your files never leave your device.
